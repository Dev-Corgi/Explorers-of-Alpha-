# inspect_trap v3

R을 누르면 기존 대각선 이동 모드를 시작하지 않고 1턴을 소모한다. 그 순간
현재 조작 포켓몬의 **인접 8칸**에 있는 숨겨진 함정을 발견한다. 자기 발밑과
2칸 이상 떨어진 함정은 대상이 아니다. 방 번호와 관계없이 복도·방 경계에서도
적용하며, 수동 조작 모드의 현재 조작 대상을 기준으로 한다.

공개 시 게임의 함정 가시성 갱신과 워프 효과음을 사용한다. Y 방향전환 모드에서는
이 동작을 수행하지 않는다.

발견은 게임의 실제 발견 상태로 기록한다. R을 놓아도 함정은 계속 보인다.
아이템·숨겨진 계단은 변경하지 않는다. 미니맵과 바닥 표시도 갱신한다.
v1의 방 전체 반투명 미리보기, 그래픽 복사와 블렌딩 변경은 제거했다.

모든 함정은 효과가 한 번 실행되면 게임의 기존 제거 경로에서 소모된다.
랜덤 함정도 선택된 효과를 처리한 뒤 원래 함정이 제거된다.
회피·불발 등으로 효과 실행에 도달하지 않은 경우에는 이 규칙으로 제거하지 않는다.
효과가 실행됐지만 대상이 면역이거나 효과를 받을 수 없는 경우에도 소모된다.
원래부터 있던 별도 해제·제거 규칙은 유지한다.

- ov29 `0x022F1E98`: 기존 R 대각선 이동 모드 토글을 제거하고 함정 공개·턴 종료를
  수행한다.
- 기존 `0x022EF700` 함정 발견 함수를 8번 호출하고, 발견이 있을 때만
  `UpdateMinimap`과 `UpdateTrapsVisibility`를 호출한다.
- ov29 `0x022EE2C4`: `TryTriggerTrap`에서 `ApplyTrapEffect` 실행 뒤의 제거 판정을
  항상 참으로 설정한다. 효과 실행 전의 보호·불발 판정은 유지한다.
- 실행 코드는 동적으로 배정한 ov36 동굴에 둔다. 기존 1024바이트 예약은 유지한다.
  새 문자열은 없으며 한글 패치는 계속 마지막에 적용한다.

검증: 저장소 루트에서 Unicorn이 있는 Python으로 실행한다.

```powershell
.venv\Scripts\python.exe true_patches\inspect_trap\test_runtime.py
```

테스트는 실제 적용 엔진과 조립된 ARM 코드를 사용하며 ROM을 저장하지 않는다.
게임 화면의 최종 외형 검증은 별도로 필요하다.
