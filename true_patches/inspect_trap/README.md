# inspect_trap

Y 방향 전환 그리드가 떠 있는 동안, 조작 중인 포켓몬과 같은 방의 숨겨진
함정을 50% 불투명도로 미리 표시한다. 복도에서는 표시하지 않는다.
이미 발견된 함정, 아이템, 숨겨진 계단은 기존 처리를 유지한다.
방향 전환을 취소하거나 Y를 놓으면 기존 그리드 정리 함수가 미리보기도 지운다.
함정의 발견 여부, 타일, 발동 조건, 미니맵 데이터는 수정하지 않는다.

`control_mode_enhance` 다음에 적용하며 새 문자열은 없다. 풀스택 등록은
`patch_engine/build_full_stack.py`와 `patch_engine/catalog.yaml`에 있다.

## 구현

- US Alpha ov29 `0x022F2FB0`: Y 입력 렌더러의 `DrawTileGrid` 호출만 감싼다.
  위치 선택 화면의 별도 그리드 호출은 그대로다. 전달된 조작 포켓몬의 위치로
  방을 판정하므로 수동 조작 모드에서도 현재 조작 대상을 따른다.
- ov29 `0x02337634`: 그리드의 8×8 하위 타일을 선택할 때 숨겨진 함정이면
  원래 함정 그림을 BG2 여유 문자 슬롯으로 복사한다. 팔레트와 반전 비트를 유지한다.
- ov29 `0x0233780C`: 원래 그리드 삭제 뒤 블렌딩 설정을 복구한다.
- BG2 미리보기 문자 슬롯은 `0x310..0x3F0`이다. 원래 BG2 그림의 끝
  `0x6060` 이후이며 BG3 그림 시작 이전인 VRAM `0x06016200..0x06017E20`을
  사용한다. 매번 필요한 그림을 복사하므로 층이 바뀌어도 그림 캐시가 남지 않는다.
- Y를 누른 동안 BG2를 BG3 위에 8/16 + 8/16으로 합성한다. 이때 같은 레이어의
  그리드도 반투명해진다. 원래 메인 화면 블렌딩 설정 10바이트는 종료 시 복구한다.
- 실행 코드와 임시 상태는 적용 엔진이 배정하는 ov36 동굴에 함께 둔다.
  소스에 동굴 주소를 고정하지 않는다.

## 검증

저장소 루트에서 Unicorn이 있는 Python으로 실행한다.

```powershell
.venv\Scripts\python.exe true_patches\inspect_trap\test_runtime.py
```

테스트는 기준 ROM을 읽고 실제 적용 엔진으로 메모리에만 패치를 적용한 뒤,
조립된 ARM 훅을 Unicorn에서 실행한다. ROM 파일은 저장하지 않는다.
방/복도 판정, 발견 상태 보존, 그림/팔레트/반전 비트, 취소·반복 입력,
레지스터·스택 보존, 문자 영역 경계와 모듈 훅 충돌을 검증한다.
게임 전체 실행과 화면의 최종 외형 검증은 별도로 필요하다.
