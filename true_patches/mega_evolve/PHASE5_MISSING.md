# 페이즈 5 — 이미지 보류 처리 결과

기존 보류32개 형태를 모두 처리했다. 현재 이미지 보류는0개이며, 새 일반
진화체4개 성별 ID까지 포함한1118개 추가 항목에586개 고유 패키지를 연결한다.
이로치 메가는 모두 이로치 **아우라**를 사용한다.

| 대상 | 처리 |
|---|---|
| 킹크랩 | 기본형에 일반 아우라 생성 |
| 노고치 계열 | 노고고치 추가 후 노고고치 일반/이로치 아우라 연결 |
| 핫삼 | 기본형에 일반 아우라 생성 |
| 노라키 계열 | 신비록 추가 후 신비록 일반/이로치 아우라 연결 |
| 무장조·다크라이 메가 | 공식 참조에 구별되는 이로치 색상이 없어 임의 팔레트 스왑 후 아우라 |
| 마기라스·요가램 메가 | 공식 이로치 참조 팔레트 스왑 후 아우라 |
| 치렁 | 걷기 동작이 있는 기본형 일반/이로치 원본에 아우라 |
| 라티오스 메가 | 걷기 동작이 있는 공식 메가 이로치 원본에 아우라 |
| 원시 가이오가·그란돈 | 공식 이로치 원시회귀 원본에 아우라; 기존 원점 ID별 동일 패키지 공유 |

노고고치의 일반 ID는2269/2270, 신비록은2271/2272다. 기존 메가·이로치
메가 ID를 유지하며 새 일반 진화체를 그 원점으로 연결했다. 두 진화 조건은
레벨20이고 기술목록은 현재 ROM에서 지원하는 기술만 사용한다.

원시회귀는 이미 메가 단계다. 별도의 추가 메가 단계는 진화 선택지에 넣지
않는다. 메가/이로치 샘 진화 활성화는 페이즈6이며 명시적 경로는
[phase5_evolution_routes.json](data/phase5_evolution_routes.json)에 고정했다.

생성 원본·팔레트·도구·결과 해시는 [phase5_repairs.json](data/phase5_repairs.json),
종 ID별 연결은 [phase5_assets.json](data/phase5_assets.json)에 있다.
원본 SpriteCollab·사용자 아우라 도구·NDS 파일은 수정하지 않았다.
