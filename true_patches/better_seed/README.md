# better_seed v1

폭렬의 씨앗을 던져 적에게 명중시키거나, 먹어서 앞의 적을 공격하면 대상의
위치에서 반경 2의 폭발을 일으킨다. 기존 단일 대상 위력 80 피해를 이 폭발로
대체하며, 중심의 적과 범위 안의 포켓몬에게 각각 위력 100의 피해를 계산한다.
씨앗 사용자의 능력치를 사용하며, 100 고정 피해나 대상 HP 비례 피해가 아니다.
범위 안의 아군과 사용자도 피해를 받을 수 있다. 아군 명중은 앞서 적용된
폭렬의 씨앗 효과를 그대로 사용한다.

`TryExplosion`의 실제 범위 순회, 연출, 벽/바닥 아이템 처리, 습기 특성 및
비에 의한 폭발 억제, 폭발 면역 검사를 재사용한다. 살아 있는 대상에서 폭발을
시작하므로 기존 단일 대상 피해로 적이 먼저 사라지는 문제를 피한다. 중심
좌표도 별도로 복사해 피해 처리 중 엔티티가 제거돼도 위치가 유지된다.

씨앗의 폭발에만 전용 피해 표시를 넘기고, 원래 폭발 피해 함수의 마지막
피해 호출에서 `DealDamageProjectile`에 위력 100을 전달한다. 일반 폭발 함정,
자폭, 대폭발의 HP 비례/고정 피해는 기존 호출로 이어진다. 새 효과는 전역
활성화 상태를 사용하지 않아 다른 폭발로 피해 규칙이 새지 않는다.

`damage_formula` 다음에 적용한다. 세 호출 지점의 이전 대상은 적용할 때
해석하며, 동굴도 overlay36에서 동적으로 할당한다. 추가 문자열은 없다.

검증:

```powershell
.venv\Scripts\python.exe -B true_patches\better_seed\verify.py
```

기준 Alpha와 기존 영문/한글 풀스택의 임시 사본에 모듈을 적용한다. 실제 ARM
씨앗 처리와 폭발 범위 순회를 실행하고, 피해 계산·타일 조회·연출 보조 서비스는
검사 환경에서 제공한다. 던지기/먹기, 중심과 주변 적/아군, 사용자 범위 포함,
범위 밖 제외, 위력 100과 씨앗 사용자 전달, 폭발 억제·면역, 아군 명중 시 기존
효과, 일반 폭발의 기존 피해 경로를 확인한다. 배포 롬을 다시 빌드하지 않는다.
